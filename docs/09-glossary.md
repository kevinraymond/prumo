# 09 — Glossary

The TeX ecosystem words this pack uses, in the order you will meet them. Enough to read the
other docs and `prumo.sty`; not a TeX course.

## The stack

- **Engine** — the binary that typesets: `pdftex`, `xetex`, `luatex` (and `luahbtex`, LuaTeX
  with HarfBuzz). All understand Knuth's TeX plus their own extensions (pdfTeX: `\pdfelapsedtime`;
  XeTeX: `\elapsedtime`; LuaTeX: Lua, where l3kernel's timer reads `os.gettimeofday()`).
- **Format** — a preloaded memory image of macros, hyphenation patterns and settings, built
  once by `fmtutil` and loaded at startup: `pdflatex.fmt` is pdfTeX + LaTeX. `pdflatex` the
  command is `pdftex -fmt=pdflatex`. Formats live in `TEXMFVAR`/`TEXMFSYSVAR`, which is why they
  show up in `.fls` as INPUT but not in the tlpdb.
- **Kernel** — LaTeX itself (`latex.ltx`), released twice a year, versioned by date
  (`\fmtversion`, e.g. `2023-11-01`). The **hook management system** (`\AddToHook`,
  `\UseHook`) arrived 2020-10-01; expl3 was folded into the kernel 2020-02.
- **expl3 / l3** — the LaTeX3 programming layer (`\ExplSyntaxOn`, `\cs_new:Npn`, `\iow_now:Nx`,
  `\sys_timer:`). `prumo.sty` is written in it because it is cleaner than 2e internals and
  ships with the kernel.
- **Distribution** — TeX Live (everywhere), MacTeX (TeX Live for macOS), MiKTeX (Windows-first,
  installs on the fly). Debian/Ubuntu repackage TeX Live without `tlmgr`.
- **texmf trees** — the directory roots the engine searches, named by kpathsea variables:
  `TEXMFDIST` (the distribution's files), `TEXMFLOCAL` (admin additions), `TEXMFHOME`
  (`~/texmf`, user additions), `TEXMFVAR`/`TEXMFSYSVAR` (generated: formats, `.pk` fonts, font
  maps), `TEXMFCONFIG`. `kpsewhich -var-value TEXMFDIST` prints one; `kpsewhich foo.sty` finds a
  file the way the engine would. `ls-R` is the per-tree filename cache (`mktexlsr` rebuilds it).
- **kpathsea** — the path-search library every engine uses; `TEXINPUTS=dir:` prepends a
  directory (the trailing colon keeps the defaults).

## Package management

- **tlmgr** — TeX Live's package manager. `tlmgr info`, `tlmgr install`, `tlmgr remove`,
  `tlmgr search --global --file foo.sty` (which package provides a file), `tlmgr list
  --only-installed`.
- **tlpdb** — `texlive.tlpdb`, the plain-text database tlmgr reads: one stanza per package with
  `depend`, `runfiles`, `docfiles`, `execute` lines. The installed copy is under
  `<TEXMFROOT>/tlpkg/`.
- **Package / collection / scheme** — a TeX Live *package* is a unit of files (often, but not
  always, one CTAN package); a *collection* is a set of packages (`collection-fontsrecommended`);
  a *scheme* is a set of collections (`scheme-full`, `scheme-medium`, `scheme-basic`,
  `scheme-minimal`, `scheme-infraonly`). Installing a collection installs its members; removing
  one does not remove them.
- **CTAN** — the Comprehensive TeX Archive Network, where packages are published; TeX Live
  pulls from it. `prumo.sty` could go there on its own.
- **LPPL** — the LaTeX Project Public License, the default license for CTAN packages.

## Files a build touches

- `.tex` source; `.cls` class (`\documentclass{obra}` → `obra.cls`); `.sty` package
  (`\usepackage`/`\RequirePackage`); `.clo` class option file (`size11.clo`); `.def`
  driver/definition file (`pdftex.def`, `puenc.def`); `.cfg` configuration; `.ltx` kernel-level
  code; `.ldf` babel language file; `.fd` **font definition** file (`t1pcr.fd` = encoding T1,
  family pcr); `.trsl`, `.lua`, `.mkii` — package-specific.
- `.aux` cross-reference data written on one run and read on the next (hence multiple passes);
  `.toc`, `.lof`, `.out` (hyperref bookmarks) likewise; `.log` the transcript; `.fls` the
  **recorder** file (`-recorder`: every file read/written, one per line); `.fmt` the format.
- **Fonts**: `.tfm` metrics (what TeX actually reads to typeset — loading one is "loading the
  font"); `.vf` virtual fonts (remap to other fonts); `.pfb`/`.pfa` Type 1 outlines (what
  pdfTeX embeds); `.otf`/`.ttf` OpenType/TrueType (XeTeX/LuaTeX load these directly via
  fontspec); `.pk` bitmap fonts rendered on demand by `mktexpk` when no outline exists
  — produce **Type 3** fonts in the PDF, which look bad when zoomed and are the classic sign of a
  missing `cm-super`/`lmodern`; `.map` font map files (`pdftex.map`, generated by `updmap`) that
  tell pdfTeX which `.pfb` goes with which `.tfm`; `.enc` encoding vectors.
- **NFSS** — LaTeX's font selection scheme: encoding/family/series/shape/size
  (`T1`/`pcr`/`m`/`n`/`10pt`). `\DeclareFixedFont` resolves one immediately (loads the `.tfm`);
  `\fontfamily{pcr}\selectfont` resolves lazily. A font that is *loaded* (`.tfm` read) but never
  *used* (no glyph set) is never embedded in the PDF.

## Timing

- **Scaled seconds** — 1/65536 s, the unit of `\pdfelapsedtime`, `\elapsedtime` and therefore
  `\sys_timer:`. 65536 = 1 s; 655 ≈ 10 ms.
- **Phases** — the run cut at the probe's records: startup (to the first record), preamble
  (to `predoc`), begin-document (to `docstart`), typesetting, shipout, end-document (to the
  last record), finalization (after it, until the process exits). Each leaves out the
  shipouts inside it and shipout holds them all, so the seven add up to the wall time.
- **Inclusive / exclusive** — as in any profiler: inclusive = from `pkg+` to `pkg-` including
  everything it loaded; exclusive = inclusive minus children. siunitx inclusive 82 ms,
  exclusive 54 ms: 28 ms of it was `translations` and friends.
- **Preamble / body** — everything before `\begin{document}` (package loading: the part the
  profiler can attribute) vs typesetting (attributed per page via `shipout/after`).
- **Shipout** — the moment a finished page is written to the PDF. `shipout/before|after` hooks
  bracket it.

## Hooks and kernel internals used by the probe

- `\AddToHook{<hook>}{<code>}` — register code; generic hooks `file/before`, `file/after`,
  `package/before`, `package/after`, `class/before`, `class/after`, `begindocument`,
  `enddocument`, `enddocument/end`, `shipout/after`; named variants
  `package/<name>/before` etc. exist too.
- `\CurrentFile` — inside file hooks, the file name as requested; `\CurrentFilePath`,
  `\CurrentFileUsed` give the path and the resolved name.
- `\@currname`, `\@currext` — inside package/class hooks, the unit's name and extension.
- `\@raw@opt@<name>.<ext>` — the raw option string requested for that package (2021-06+).
- `\ver@<name>.sty` — the kernel's "this package is loaded, version string" marker. Defining it
  by hand makes `\usepackage` a no-op: the blocking trick in `06`. `\opt@<name>.sty` is the
  matching options marker, checked to raise "Option clash".
- `\jobname` — the base name of all output files; `texput` is the fallback when TeX has to open
  the log before it knows the main file, which is what happens when a package is loaded from the
  command line without `-jobname`.
- `-interaction=nonstopmode`, `-halt-on-error` — don't stop at errors / do stop at the first
  one. prumo uses `nonstopmode` for the baseline and reads exit codes plus the log.
- `max_print_line` — the log/terminal wrap width (79 by default). Affects log parsing; does
  **not** affect `\write` to a file stream, which is why the record file is not the log.

## Tools around the build

- **latexmk** — the standard build runner (reruns until stable, runs biber/makeindex).
  `-usepretex`/`-pretex` inject code before the main file; `-jobname` as with the engine;
  `-recorder` is on by default in latexmk, which is how it tracks dependencies.
- **Poppler** `pdffonts`, `pdftotext`, `pdfinfo`, `pdftoppm` — read fonts, text, metadata,
  raster pages of a PDF. Also `xpdf`'s versions; Debian package `poppler-utils`.
- **texlogsieve**, **texfot**, **texlogfilter** — log filters; texlogsieve rebuilds nesting from
  the log's parentheses.
- **texprof** — Ruckert's profiling engine, TeX + e-TeX + Prote with DVI output (TeX Live,
  `hitex` package); per-line and per-macro.
- **TinyTeX** — Yihui Xie's small TeX Live with install-on-demand; the R world's default.
- **Tectonic** — a Rust reimplementation of XeTeX with self-contained bundles; the other way of
  getting "a small TeX".
- **texlab** — the LaTeX language server (Rust); **TeXstudio** — the editor the original
  requester uses; prumo should be runnable from its "user commands".
